# Pretrained model policy

Pretrained forecasting and financial-language weights are useful priors, not pretrained profitable strategies. They may be installed only by explicit operator action with an exact upstream revision, licence, local path and SHA-256.

TimesFM, Chronos, Moirai and FinGPT integrations are isolated behind the same model and feature provenance rules. A pretrained model cannot become an active paper model merely because weights load successfully. It must produce point-in-time outputs, pass calibration and sealed-holdout comparisons against simple baselines, and remain compatible with the runtime contract.

Large weights are never downloaded in CI and are never committed to this repository.
